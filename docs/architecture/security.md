# Seguranca para Dados Sensiveis

Recomendacoes minimas:

- HTTPS em producao.
- Senhas com hash forte.
- Secrets fora do Git.
- Controle de permissao por role/policy.
- Auditoria para leitura/exportacao/alteracao de dados sensiveis.
- Backups testados.
- Banco separado por cliente quando isolamento for requisito.
- Logs sem dados sensiveis.
